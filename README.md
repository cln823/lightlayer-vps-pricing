## 洛杉矶三条线路，$20 的差价买的是什么

同一个机房、同样的 1 核 1GB / 50GB SSD，Global 是 $29.99/年，Standard 是 $39.99/年，Premium 是 $49.99/年。三档之间各差 $10，最高和最低差 $20，摊到每月是 $1.67。

这 $1.67 买的只有一样东西：回程路由。Premium 走 CN2 和 CMIN2，Standard 是常规优化，Global 是国际线路。机房都在洛杉矶，物理距离一样，但从中国大陆访问时的绕路程度完全不同，晚高峰的差别比配置差别明显得多。

判断方法很直接，不用看宣传语：

- 用户主要在美西或全球各地，对大陆访问没要求 → Global，$29.99/年够用。
- 用户在中国大陆，站点打开速度直接影响留存 → Premium，$49.99/年。一年多花 $20，比事后换机房重装迁移便宜。

机房多不等于每条线路都快。LightLayer 覆盖 25 个以上机房，同一个城市往往同时卖 Global、Standard、Premium 三种线，价格只差 $10 到 $20，体验差一截。挑的时候先定线路等级，再定城市。

## 哪些情况不适合选它

**长期跑满带宽的用途。** 三档套餐都标"不限流量"，但端口速率封顶在 100Mbps 或 200Mbps。这个组合适合网页、API、代理这类低带宽占用的场景；做视频分发、大文件镜像、持续满速下载，端口会一直顶在上限，不如直接看独服。

**需要按小时计费、随时销毁退余额的项目。** 这里的计费单位是月和年，不是小时。临时跑几小时的压测、一次性数据抓取，用月付 $4 也能接受，但别指望按用量精确结算。

**必须随时升降配的稳定业务。** 年付款在周期内是固定的，中途改配置通常要重新下单。配置可能变化的项目，一开始就选 Pay As You Go，多花的那点钱买的是不用迁移。

**第一年就想换三家试试的人。** $24.99 的年付意味着一次性锁定，试错成本比月付高。先用 $4/月 跑两周，确认路由和稳定性，再决定要不要转成年付，这个顺序更稳。
